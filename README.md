## Features

- Removes duplicate rows
- Detects missing values
- Cleans text fields
- Fills missing numeric values
- Generates a cleaned CSV file
- Creates a cleaning report

## Technologies

- Python
- Pandas

## How to Run

Install pandas:

```bash
pip install pandas

Run the program:
python main.py

Input
Place your CSV file in the project folder as:
sample.csv

Output
The script creates:
cleaned_data.csv
cleaning_report.txt

Use Cases
This tool can be used for:
- Basic CSV cleaning
- Removing duplicate data
- Filling missing values
- Simple data preprocessing
- Repetitive data-processing tasks
